Crescendo / Diminuendo

Não é um ícone fixo — é a forma normal mudando de tamanho: cresc. 1.0×→1.4× · dim. 1.0×→0.4×.

Todas as cores possíveis

Cada roda é uma oitava. Ângulo = nota (deslocado pela alteração) · raio = dinâmica, do centro (mais apagada) até a borda (mais cheia). Só as combinações que o projeto realmente gera.
